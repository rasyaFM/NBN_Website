Two Way Radio

A two-way radio is simply a radio that can both transmit and receive (a transceiver). In broader terms, two-way radio refers to a radio system mainly used for group-call communication.

Two-way radio can be used for your business communication needs.

01 · Fixed channels

Conventional System

Conventional system is the most basic radio communications system. Radios operate on fixed channels and each user group is permanently assigned a fixed frequency or a set of frequencies.

⌁
02 · Shared resources

Trunking System

Trunking allows multiple user groups to share a pool of radio channels. System logic automatically selects the physical radio frequency channel, so channel assignments happen automatically and groups do not hear each other’s conversations. This arrangement helps conserve limited radio frequencies and provides advanced features.
